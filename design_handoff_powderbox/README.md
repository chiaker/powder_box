# Handoff: PowderBox — мультитул для лыжников и сноубордистов

## Overview
Веб-сервис погодной аналитики для катания: прогноз по высотам курорта (вершина / середина / низ склона), эвристика «лучший день для катания», снежные email-алерты и сравнение курортов по одинаковым метрикам. Десктоп, язык интерфейса — русский, бренд «powderbox*» остаётся латиницей. Есть светлая (рассвет) и тёмная (закат) темы с анимированным переключением.

## About the Design Files
Файл `PowderBox.dc.html` — **дизайн-референс в HTML**, прототип внешнего вида и поведения, а не production-код. Задача: **воссоздать эти экраны в целевом стеке проекта** (React, Vue, Svelte и т.п.) по его существующим паттернам. Если стека ещё нет — выбрать подходящий фреймворк и реализовать дизайн в нём. Вся разметка экранов лежит внутри секций с `data-screen-label`; стили — inline (каждое значение видно прямо на элементе).

## Fidelity
**High-fidelity.** Цвета, типографика, отступы и контент финальные — воспроизводить попиксельно, используя библиотеки/дизайн-систему целевой кодовой базы.

## Interactions & Behavior
- Пульсирующие точки: keyframes scale(1→.8) + opacity(1→.45), 2.4s ease-in-out infinite, ступенчатые delay в списках.
- Падающий снег в hero: 5 частиц, translateY на высоту блока, 12–16s linear infinite (не переусердствовать — плотность оставить как в референсе).
- Навигация: карточки «Мои курорты» → страница курорта; «Сравнить все →» → сравнение; ✕ в шапке колонки удаляет курорт из сравнения; фильтры секторов переключают карту.
- Формы email: одно поле + кнопка; успешная подписка может заменять плашку подтверждением (в макете не показано — на усмотрение).
- Hover: ссылкам достаточно смены цвета на #35507e/#3d8fdd; крупных hover-эффектов в дизайне нет.
- Переключение темы: см. экран 7a — кросс-фейд неба 1.8s, переезд солнца по дуге 1.8s, перекраска UI .9s. Выбор темы стоит сохранять (localStorage / профиль).

## State Management
- Тема (light / dark) — глобальный флаг, персистится.
- Выбранный «домашний» курорт (подсветка колонки/карточки #f8fbfd).
- Список курортов пользователя (до 6 в сравнении).
- Данные: прогноз по 3 высотам, снег 24/48ч, ветер, статус подъёмников/трасс/секторов, очереди, индекс катания на 7 дней (число 0–10 + выделение максимума), email-подписка.
