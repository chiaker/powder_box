# PowderBox — логотип

Шрифт: **Rubik 600** (Google Fonts), трекинг −0.03em. Звёздочка — акцент.
В SVG подключён @import Rubik — при открытии файла напрямую нужен интернет, иначе подставится системный шрифт. В вебе логотип рисуется тем же Rubik, что и весь сайт, поэтому совпадает точно.

## Файлы
| Файл | Назначение |
|---|---|
| `pb-mark-dark.svg` | знак pb* на тёмно-синей плашке (#1b2a4a), радиус 28/128 — основной |
| `pb-mark-warm.svg` | знак на тёплой плашке #ffd9b0 (для тёмных фонов/подвала) |
| `pb-mark-round-dark.svg` | круглая версия (аватар, соцсети) |
| `pb-mark-transparent.svg` | знак без плашки, текст #132030 |
| `powderbox-wordmark-dark.svg` | надпись powderbox* для светлого фона |
| `powderbox-wordmark-light.svg` | надпись для тёмного фона/градиента |
| `powderbox-lockup.svg` | знак + надпись (только для отдельных материалов) |
| `favicon.svg` | фавикон 128×128 |

## Правила
- **Не дублировать**: в шапке сайта — только надпись powderbox*; в подвале / фавиконе / аватарах — только знак pb*.
- Минимальный размер знака: 24px; надписи: 100px по ширине.
- Цвета: тёмно-синий #1b2a4a, текст #132030, тёплый акцент #ffd9b0 (на тёмном) / #e0a763 (на светлом).
- Охранное поле вокруг знака — не менее высоты буквы «b».

## PNG (шрифт уже впечатан)
Папка `png/` — растр, отрендеренный настоящим Rubik 600, шрифт не нужен:
- `pb-mark-dark.png` / `-warm` / `-round` / `-transparent` — 512×512
- `powderbox-wordmark-dark.png` / `-light` — надпись
- `powderbox-lockup.png` — знак + надпись
- `favicon-32/64/180/512.png`

SVG-версии остаются векторными, но зависят от Rubik. Если нужен SVG без зависимости от шрифта — откройте SVG в Figma/Illustrator с установленным Rubik и примените «Перевести в кривые» (Outline / Flatten).
